Advanced Metadata

Builds a searchable index of custom audio metadata. Jellyfin is never modified.

Create Single Mapping

This must match the ID3 tag EXACTLY as written in your files/audio library.
Enter the desired display name, such as Record Label (instead of LABEL). If this is blank, the ID3 tag name will be used.
Choose where the tag is applied. Songs only applies it to individual tracks. Adding Parent Albums also applies it to the album, which is needed for album-level searches.
If a tag holds several values separated by a character — for example Pop/Rock — enter that character here. Each value becomes its own searchable entry.
