Manage Data

This tool shows the data that has been mapped from plugin scans. It is stored in the plugin's internal database and is NOT in Jellyfin's core.

Every result row has Edit and Delete links. Editing or deleting a value changes only the plugin's index — your audio files are never modified, and the change survives future scans.

Search by content item

Multiple words are matched together, so "Artist Album" works. Results are grouped by item and show every indexed value across all mappings and levels.

Scan Mappings

A standard scan only looks for tracks that are new or changed since the last run, so it is usually quick. It reads your mapped tags into the plugin's own index — your audio files and Jellyfin's database are never modified.

A standard scan only picks up changed files. If you have just added a new mapping, tick Full Rescan below — otherwise the new mapping will have nothing to show.

Backups

Plugin data lives alongside the plugin on the server — on a Synology NAS that is typically /volume1/@appdata/jellyfin/data/plugins. The exact path is shown above. Include that folder in your NAS backups.
